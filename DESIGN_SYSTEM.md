# Design System

## Experience
- Calm, book-focused workspace; minimal visual noise.
- Responsive: desktop-first editor, usable tablet/mobile navigation.
- Accessible keyboard navigation and visible focus.
- Bangla and English labels supported from day one.

## Typography & Print Rules
- UI font and manuscript font are separate settings.
- Master Book Print Preset: **215 mm × 275 mm** with mirror margins (`18mm` top, `20mm` bottom, `22mm` inside + `5mm` gutter, `16mm` outside).
- Bangla Body Font: `Noto Serif Bengali`; Bangla Headings: `Noto Sans Bengali`; Latin Font: `Inter`.
- Book Callouts: Primary Navy `#123B6D` (Quote Box `#F4F7FB`) and Accent Orange `#F26B21` (Exam Tip Box `#FFF4ED`).
