# Design System

## Experience
- Calm, book-focused workspace; minimal visual noise.
- Responsive: desktop-first editor, usable tablet/mobile navigation.
- Accessible keyboard navigation and visible focus.
- Bangla and English labels supported from day one.

## Typography
- UI font and manuscript font are separate settings.
- Never assume one font covers Bangla and Latin glyphs.
- Manuscript typography will be controlled by versioned book design profiles, not global UI CSS.

## Tokens
- Use Tailwind utilities and semantic CSS variables.
- Avoid hard-coded colors repeated across components.
- Keep editor canvas visually distinct from the application chrome.

## Planned design controls
Page size, inside/outside margins, gutter, body font, Bangla font, Latin font, font size, line height, paragraph spacing, chapter title style, running headers, footers, page numbering, watermark and QR code.
